# Pokémon Explorer — web

React app generated with Vite (React 19, TypeScript, Redux Toolkit, React Router, MUI). How to run it, the routes and the decisions behind them are in the [root README](../README.md).

Inside `src/`, `app/` wires the store, the routes and the layout, `shared/` holds what both domains use, and `pokemon/` and `stats/` hold one domain each.
